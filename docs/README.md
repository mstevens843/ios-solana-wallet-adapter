# Docs

This folder contains the demo guide, protocol support docs, and wallet research trail for iWA.

## Contents

- [`demo.md`](./demo.md) - complete SwiftUI URL/callback flow for a demo app.
- [`logging.md`](./logging.md) - deterministic logging format, expected flows, and privacy rules.
- [`walletconnect-reown.md`](./walletconnect-reown.md) - Jupiter Mobile / Reown companion track for WalletConnect wallets.
- [`release-checklist.md`](./release-checklist.md) - public-RC and stable-release gates.
- [`smoke-testing.md`](./smoke-testing.md) - real-device wallet smoke procedure.
- [`launch/`](./launch) - launch thread and video storyboard drafts.
- [`smoke/`](./smoke) - per-wallet smoke result stubs for Phantom, Solflare, Backpack, and Jupiter Mobile through WalletConnect.
- [`research/`](./research) - captured findings from the wallet-by-wallet survey that informed the iWA v0.1 spec, including held-out candidates such as Glow and Jupiter Mobile.
- [`../Examples/iWADemo`](../Examples/iWADemo) - SwiftUI real-device smoke app source.
